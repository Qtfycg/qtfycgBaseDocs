# qtfycgBaseDocs

存放个人开发过程中所有项目的相关文档，包括需求文档、接口文档、数据库设计、技术方案、部署文档、问题记录和版本记录。

## 仓库定位

主要用途：

* 统一管理项目文档
* 记录项目从立项到开发的完整过程
* 沉淀需求分析、接口设计和数据库设计经验
* 配合前端仓库和后端仓库进行项目说明
* 方便后续复盘、维护和简历整理

## 分支规则

本仓库采用以下分支模型：

```text
main：稳定文档归档分支
dev：日常文档维护分支
```

规则说明：

* `main` 分支用于保存相对稳定的项目文档
* `dev` 分支用于日常编写、修改和整理文档
* 日常文档修改优先提交到 `dev`
* 稳定后通过 Pull Request 合并到 `main`
* 禁止直接向 `main` 分支提交内容

## 文档维护流程

```text
dev 编写或修改文档
→ 提交修改
→ 创建 Pull Request
→ 合并到 main
```

## 提交规范

提交信息建议使用以下格式：

```text
docs: 修改文档
fix: 修正文档错误
chore: 调整目录结构或文档配置
```

示例：

```text
docs: 初始化在线点餐系统需求文档
docs: 补充用户模块接口说明
fix: 修正数据库字段说明
chore: 调整项目文档目录结构
```

## 维护说明

本仓库会随着个人项目开发过程持续更新。每个项目文档应独立存放，目录结构尽量统一，便于后续查找、维护、复盘和项目展示。
